## 0. TL;DR

Ниша «steam roulette» в EN занята наглухо (точные домены, легаси Funhaus, SGG у RU-стримеров),
но **никто не делает рулетку СКИДОК**: живые цены на секторах + вишлист + шоу-колесо + шаринг.
Перепозиционируемся из «random game picker» в **«рулетку распродажи»** — два режима:
**«что купить»** (вишлист/deals) и **«во что поиграть»** (библиотека).
Добавляем импорт библиотеки и вишлиста, лайв-комнаты для совместных спинов с друзьями,
виральные win-карточки. Дедлайн — зимняя распродажа, канал №1 — DTF (RU-сегмент пуст).

## 1. Аудит текущего состояния

### Что уже есть (сильная база)

- Колесо с честным RNG (`crypto.getRandomValues`), плавная физика, тик-звук с затуханием
- **Цены и скидки Steam на секторах** — ключевая уникальная фича
- Короткие шарибельные ссылки: immutable snapshot + mutable live (Supabase Edge Function + URL-state fallback)
- Пресеты, hide-игр, elimination-режим, shuffle
- Полная кастомизация: фоны, цвета, тексты, idle-spin
- История выигрышей с ценами
- EN/RU авто-детект, регион/валюта Steam по локали
- PWA, no signup, данные в браузере
- Лендинги EN+RU, llms.txt, edge-функция проксирует Steam API
- Стек: React 19 · TS · Vite 8 · Tailwind 4 · Framer Motion · Supabase Edge Functions · GH Pages

### Дыры (по убыванию тяжести)

1. **Нет импорта библиотеки Steam** — игры вбиваются вручную. У всех конкурентов первый
   экран — «вставь Steam-профиль». Юзер с 200 играми уйдёт к pickaga.me за 20 секунд.
   Это ворота ниши, через которые сейчас утекает весь трафик.
2. **Нет сценария нулевого трения** — первый визит = демо-колесо, которое ничего не значит.
3. **Нет вишлист-режима** — а это воплощение «рулетки распродажи» (см. §3).
4. **Нет виральной механики результата** — выигрыш живёт только внутри приложения.
5. **Нет совместного режима** — live-ссылки есть, но синхронного редактирования/спина нет.
6. EN-ключевик «steam roulette» безнадёжен в лоб — нужен обход через RU и deals-угол.

**Вывод:** мoat — не «пикер», а **price-aware shareable wheel show**. Никто не совмещает:
твой список + колесо-шоу + живые цены на секторах + share-link + elimination + EN/RU.
Вишлист как источник есть только у pickaga.me — но там нет ни колеса, ни цен, ни RU.

## 3. Позиционирование

> **«Рулетка распродажи Steam»** — крутишь колесо, оно показывает, что сегодня стоит копейки.
> Во что поиграть — и на что потратить 100₽ вместо тысячи.

Два режима, одно колесо:

| Режим | Вопрос юзера | Источник игр | Когда пик | Конкуренты |
|---|---|---|---|---|
| **Deals** | «Что купить?» | Вишлист юзера / горящие скидки дня | Распродажи (спайки трафика ×10) | **Никого — пустая ниша** |
| **Library** | «Во что поиграть?» | Библиотека Steam | Каждый вечер, ровный трафик | Все — но у нас +цены, +шоу, +ссылки, +RU |

На лендинге deals — первым экраном, library — вторым. Не смешивать в один слоган.

### Почему вишлист — скрытый козырь

Сценарий зимней распродажи: 40 игр в вишлисте, не знаешь на что хватит денег →
вставил профиль → колесо из вишлиста, **на секторах живые скидки** →
«судьба выбрала: Hades за −70%». Это настолько точное попадание в момент,
что DTF-пост почти пишет себя сам. Библиотека — рутина, вишлист — событие.

## 4. Дорожная карта фич

### P0 — до зимней распродажи (без этого не запускаемся)

#### 4.1 Импорт библиотеки Steam
- UX: поле «вставь ссылку на профиль» → парсим steamid64/vanity → колесо наполняется само
- API: `IPlayerService/GetOwnedGames` — ключ бесплатный, прячется в edge-функции
- Резолв vanity через `ResolveVanityURL`
- Приватный профиль (30%+ юзеров!) — дружелюбная инструкция со скриншотом настроек,
  не тупая ошибка
- Фильтры перед спином чекбоксами над колесом: «только неигранные», «<2ч наиграно», «короткие»
- Кэш библиотеки в edge 24ч

#### 4.2 Импорт вишлиста
- Endpoint: `store.steampowered.com/wishlist/profiles/{steamID64}/wishlistdata/` —
  публичный JSON, ключ API **не нужен**, работает годами
- Тот же резолв vanity → steamid64
- Вишлист упорядочен юзером — читаем порядок: «твой топ-3, и все на скидке»
- Кэш 6–12ч (на распродаже цены меняются, чаще не нужно)

#### 4.3 Deals-режим: колесо горящих скидок на первом экране
- Источник: `store.steampowered.com/api/featuredcategories` (specials), cc-регион,
  edge-кэш 1ч
- Новый юзер видит **реальные скидки сегодня** вместо демо-игр — ценность за 0 кликов
- Fallback: если specials не загрузились — most wishlisted / top sellers оттуда же

#### 4.4 Win-карточка для шаринга
- Canvas-генерация: обложка, название, скидка-стикер, цена, брендинг колеса
- Кнопки: «скопировать картинку», «поделиться в Telegram», «скопировать ссылку»
- OG-мета на live-ссылках: edge-функция рендерит html с og:image для ботов мессенджеров
- Каждая карточка «смотри что мне выпало» в Discord/TG = бесплатная реклама

#### 4.5 Лайв-комнаты — совместные спины с друзьями
- Техника: Supabase Realtime (уже в зависимостях, ничего не ставим),
  канал = id live-ссылки, broadcast полного состояния (JSON 2–5КБ, дебаунс 300мс)
- Совместное редактирование: игры, фоны, стили, цвета — всё синхронно у всех
- **Синхронный спин** — магия режима: спиннер генерит сид crypto-рандомом,
  шлёт в канал, все клиенты проигрывают ту же анимацию и результат.
  Честность сохраняется (сид до спина)
- Presence: «3 друга онлайн»
- Реакции-эмодзи на выигрыш — дёшево, угара много
- Конфликты: last-write-wins (для фана достаточно)
- Realtime подключать только при 2+ участниках или по кнопке «совместная сессия» —
  экономим free-лимит 200 concurrent connections (это 40–60 комнат)

#### 4.6 Запуск игры одним кликом
- `steam://run/<appid>` и `steam://install/<appid>` на win-screen
- «В Steam за 149₽» — ссылка на стор для deals-режима

### P1 — RU-захват и SEO (параллельно с P0)

#### 4.7 Programmatic SEO-страницы
- `/sale/winter` — «Рулетка зимней распродажи» (обновляется ежечасно)
- `/deals/under-100` — «Всё дешевле 100₽», `/deals/90-percent` — «Скидки 90%+»
- Статичный HTML-каркас для индекса + приложение поверх (prerender в CI)
- Long-tail: «стим скидки 90 процентов», «что купить на зимней распродаже» — конкуренция ~0

#### 4.8 RU-first ценности
- Не просто перевод UI: рубли и RU-регион по умолчанию, формулировки «во что поиграть»
- Лендинг под запросы «рулетка стим», «какую игру выбрать», «что купить на распродаже»

#### 4.9 Telegram-шаринг
- Кнопка «поделиться в TG» — одна строка, RU-аудитория живёт там
- Позже (P2): бот «/spin в чате»

### P2 — после распродажи

#### 4.10 Стримерский режим
- Чистый overlay-URL: без UI, chroma-key фон, звук — OBS browser source одной ссылкой
- Режим «только ведущий спинит, остальные зрители» = лайв-комната для стрима
- Формат доказан Funhaus (EN) и Maddyson/SGG (RU) — но tooling для стримера так и остался в 2016

#### 4.11 Групповой режим «на компанию»
- Каждый кидает игры со своих библиотек в общее колесо — «вечер пятницы»
- WeBothPlay-территория, но у нас колесо-шоу + цены + нет регистрации

#### 4.12 Умное взвешивание (опция)
- Чем больше скидка/выше рейтинг — тем шире сектор. Дефолт — честный рандом

#### 4.13 История как бэклог-трекер
- Выиграл → «прошёл» → колесо помнит. Возвращаемость

## 5. UX-полировка (первые 30 секунд решают всё)

1. **Спин — событие:** лёгкая камерная тряска на остановке, конфетти с discount-стикерами
   вместо просто лепестков. Это то, что попадёт в скринкасты на DTF
2. **Мобила — 60%+ трафика из TG/DTF:** колесо на весь вьюпорт, спин по свайпу
   (физика продолжает жест), не только по кнопке
3. **Первый рендер:** колесо крутится максимум через 1.5с после открытия,
   цены из edge-кэша, не ждать всё
4. **Сектора читаемы:** название + цена на секторе без зума; длинные названия —
   автошринк шрифта, не обрезка «Death Stranding Dir…»
5. **Deals empty state:** graceful fallback на «топ желанного»

## 6. Реализация — карта по коду

| Задача | Куда лезет | Трудоёмкость |
|---|---|---|
| `/api/library` endpoint | edge-функция `supabase/functions/fortune-wheel`, +30 строк GetOwnedGames + кэш | 0.5 дня |
| Steam API key | env-секрет supabase (`steam web api key` бесплатно на steamcommunity.com/dev/apikey) | 10 мин |
| `/api/wishlist` endpoint | та же edge-функция, wishlistdata + кэш 6–12ч | 0.5 дня |
| Импорт UI (библиотека+вишлист) | новый компонент рядом с `SteamGameSelectionModal.tsx`; табы «Библиотека / Вишлист» | 1 день |
| `/api/deals` + preload первого экрана | edge, featuredcategories, кэш 1ч | 0.5 дня |
| Win-карточка canvas | новый util + кнопка в `WinScreen*` | 1 день |
| Лайв-комнаты | `supabase-js` realtime broadcast; состояние в App.tsx уже есть; спин-сид sync | 1.5–2 дня |
| steam:// кнопки | win-screen, 20 строк | 1 час |
| SEO-страницы распродажи | CI prerender + шаблоны | 1–2 дня |
| OG-мета по ссылкам | edge рендерит html для ботов | 1 день |
| Свайп-спин на мобиле | `FortuneWheel.tsx`, физика уже есть | 0.5 дня |
| Счётчики (спины/шары) | edge + табличка, privacy-friendly, без GA | 0.5 дня |

**Итого P0+P1: ~6–8 дней. До распродажи — впритык, но успеваем.**
Порядок: вишлист+deals (1 день) → библиотека → лайв-комнаты → win-карточки → SEO-страницы.

## 8. Риски и честные оговорки

| Риск | Митигация |
|---|---|
| Steam API rate limit 100k/день | Агрессивный edge-кэш с первого дня |
| `featuredcategories` неофициален, может молча измениться | Fallback на `search/?specials=1` или IsThereAnyDeal API (free tier, легально) |
| `wishlistdata` неофициален | Тот же fallback — грейсфул деградация в ручной ввод |
| Supabase free tier: Realtime 200 concurrent, edge invocations | Realtime только для комнат 2+; мониторинг в день поста; upgrade $25 при взлёте |
| Двойное позиционирование размывает сообщение | Deals первым экраном, library вторым; один слоган = про скидки |
| Приватные профили (30%+) | Инструкция со скриншотом + fallback ручной ввод, не терять юзера |
| Сезонность deals-трафика | Library-режим = ровный фон между распродажами |
